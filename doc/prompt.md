# 数据集筛选工具集 · 开发需求

## 一、总体目标与技术栈

使用 Python + PySide6 开发一套**数据集筛选工具集**，包含两个前后衔接的 GUI 工具：

- **工具1（组级初筛）**：按"块-组"浏览数据集，将组划分为 选中 / 未筛选 / 排除 三种状态；
- **工具2（RGB/深度精筛）**：接工具1的选中区，成对对比 RGB 图与深度图，逐张删减。

技术要求：Python ≥3.12，依赖仅 PySide6 与 Pillow；使用 uv 管理项目；图片解码显示高效（缩略图异步加载），界面在任何操作下保持流畅响应。整体界面为**深色主题**（近黑背景、浅色文字、绿/红/蓝点缀色）。

## 二、数据集结构与术语

```
数据集根目录/
└── 一级目录（工件描述）           ← 称为「块」
    └── 二级目录（工件名称+工件状态）
        └── 场景目录（001、002…）   ← 称为「组」
            ├── color/          若干RGB图（.jpg/.jpeg/.png/.bmp/.webp/.tif）
            ├── depth/          若干深度图（常为16bit PNG）
            ├── camera_params/
            └── coco/
```

- 扫描规则：某目录下存在 `color/` 或 `depth/` 子目录即判定为「组」，不再向内递归；兼容大小写目录名、图片位于 color/ 下一级子目录、更深的层级嵌套；文件名支持中文、空格、括号、大写扩展名、超长路径（Windows >260 字符）。
- 工具1 仅展示组内 color/ 的 RGB 图；工具2 同时使用 color/ 与 depth/。
- 深度图显示时按最小-最大拉伸归一化为 8bit 灰度（仅影响显示，不改动文件）。

## 三、项目结构

```
项目根目录/
├── run.py              启动入口：直接启动工具1（无任何中间界面）
├── src/                工具源码（含两工具与共享组件）
├── tests/              测试脚本（数据集生成 + 各工具冒烟/功能/回归测试）
├── doc/                文档
└── filtering/          数据工作目录（数据与状态文件不入库，保留目录结构）
    ├── original_data/    原始数据集存放目录
    ├── data/             最终筛选拷贝输出目录（「拷贝」默认目标）
    ├── test_data/        测试用模拟数据集
    └── *.json            筛选状态文件（导入/导出默认位置）
```

- 运行方式：`uv run run.py` 启动工具1；工具2在界面内同窗切换进入，或单独启动其源码脚本。
- 所有文件对话框的默认目录：「选择数据集」默认打开 `filtering/`，JSON 读写默认 `filtering/`，拷贝默认 `filtering/data/`。

## 四、通用界面与交互规范

1. **窗口模型**：两个工具运行在**同一个窗口**内（宿主窗口 + 页面切换），窗口标题随当前工具变化；切换瞬间完成，窗口位置/尺寸/任务栏项保持不变。
2. **工具栏**（两工具统一布局）：
   `[选择数据集] [功能按钮组（左对齐，宽度贴合文字，不随布局拉伸）] ……弹簧…… [→ 切换按钮（最右端）]`
   - 工具1功能按钮：每组显示数量标签、count 输入框（点击后获得焦点）、保存、导入、导出；
   - 工具2功能按钮：拷贝、导入、导出。
   - **数据集路径与统计信息一律显示在左下角状态栏**，顶栏不显示路径/统计。
3. **状态栏**（左下角为主信息区）：
   - 工具1：`数据集：路径 ｜ 块 B · 组 G · RGB I 张 ｜ 未筛选 x（xi） · 已选 y（yi） · 已排 z（zi）`，实时更新；
   - 工具2：`数据集：路径 ｜ 保留RGB tr 张 · 保留深度 td 张 ｜ 剩余组 g ｜ 块 b ｜ 组总数 N`；
   - 右侧永久区显示缩略图加载进度（`缩略图加载中 n/总数`、`⚠ N 张加载失败`）与快捷键提示；
   - 动作反馈（保存、导入成功等）通过状态栏内独立的通知区域显示：简短结果文本，数秒后自动消失，与主信息区互不遮挡，通知内容不含路径。
4. **加载过程态**：任何数据加载/导入开始时，状态栏立即切换为过程提示（如"正在扫描数据集：路径 …"），完成后切换为新数据集的统计信息，失败时还原为当前数据集的真实统计；状态栏始终只反映当前生效的数据集。
5. **缩略图**：
   - 异步加载（线程池 + LRU 缓存 + 可见优先调度），卡片分批增量创建，大数据集下滚动/操作流畅；
   - 工具1组卡片内的缩略图按图片真实长宽比贴紧排布（加载后收缩占位尺寸，行间仅数像素）；
   - 工具2的缩略图为固定正方形（约190px），图片居中衬在同尺寸深色底块上，与缺图占位框视觉等高。
6. **放大查看**：
   - 点击缩略图与按空格打开**完全相同**的放大界面，点击时直接定位到被点的图/图片对；
   - 图片初始按"适应窗口"显示：小图放大填充、大图缩小适配（既能看全又能看清细节）；
   - RGB/深度并排显示时左右**共享同一缩放比例**（取共同适配值，滚轮缩放双侧同步，双击共同复位），保证对比对称；
   - 单图支持滚轮缩放（锚定光标）、拖拽平移、双击复位、Esc 退出。

## 五、工具1 · 组级初筛

### 5.1 界面布局

三区横向布局：**左侧选中区 / 中间未筛选区（主操作区，占主要宽度）/ 右侧排除区**（默认宽度约为 360:940:360，左右两区一致）。

- **未筛选区**：按「块」分节组织；块头含块名、组数/图片数统计、「一键选中」「一键排除」按钮，可折叠；组卡片 = 标题（相对路径）+ 张数（含抽样说明）+ 「选中」「排除」按钮 + 缩略图行；
- **选中区 / 排除区**：无块结构，组卡片按绝对路径显示，各带「恢复到未筛选」按钮；
- 启动时焦点位于主窗口，count 输入框点击后才获得焦点，快捷键自启动即可用。

### 5.2 功能

| 功能 | 说明 |
|---|---|
| 选择数据集 | 加载数据集根目录；已有筛选状态时确认丢弃 |
| 每组显示数量 count | 输入框 + 保存；组内图片 ≥ count 时随机抽样 count 张显示（1~500，默认6），保存后全量重采样 |
| 组操作 | 选中 / 排除 / 恢复到未筛选；块级一键选中/一键排除 |
| 移动规则 | 组被选中/排除 → 移至目标区**最上方**；恢复 → 回未筛选区**最上方**（其所属块同步置顶） |
| 撤销 | S 逐步撤销上一次选中/排除（含一键操作产生的多条） |
| 查看图片 | 缩略图左键 → 放大浏览（定位该图）；右键菜单：查看 / 复制图片（图像数据+文件引用）/ 复制路径 / 打开所在文件夹 |
| 导出 | 状态 JSON 默认存 `filtering/`，文件名 `粗筛_数据集名.json`（数据集名为根目录名） |
| 导入 | 校验 JSON 记录的数据集根目录与当前一致，不一致**拒绝**；缺失组提示后忽略 |

### 5.3 快捷键（作用于未筛选区最上方的组）

| 键 | 功能 |
|---|---|
| `A` | 选中最上方未筛选组 |
| `D` | 排除最上方未筛选组 |
| `S` | 撤销上一步 |
| `空格` | **仅**放大查看未筛选区最上方组（放大中 A/D 翻页、Q/Esc 退出、可复制当前图） |

### 5.4 导出 JSON 格式

```json
{
  "未筛选区": ["组绝对路径", ...],
  "选中区":   ["组绝对路径", ...],
  "排除区":   ["组绝对路径", ...],
  "统计信息": {
    "数据集根目录绝对路径": "", "总块数": 0, "总组数": 0,
    "选中组数": 0, "排除组数": 0, "总RGB图数": 0,
    "选中总RGB图数": 0, "排除总RGB图数": 0
  }
}
```

## 六、工具2 · RGB/深度精筛

### 6.1 界面布局

- **左侧**：可折叠目录树（块 → 组），宽度与工具1选中区一致；组节点实时显示 `RGB n ｜ 深度 m`（保留数）；块节点显示剩余组数；完全排除的组自动移入「已排除组」节点（可恢复整组），无剩余组的块自动隐藏；
- **右侧工作区**：当前组的图片对按**多列网格**排布（按宽度自适应2~3列，紧凑无大片空白）；
- **图片对卡片**（固定紧凑宽度）：
  - 头行：`图片对：名称` + 状态标签（左对齐紧随编号）+「排除图片对」按钮（右上角）；
  - 主体：左 RGB 图、右深度图（缺失侧显示等高虚线占位框）；「排除RGB图」「排除深度图」按钮分别位于对应图片正下方；
  - 排除反馈：单边排除 → 该侧**红色边框**+变暗；整对排除 → 卡片红框；按钮均为开关可恢复；
- 组头部：「排除整组 / 恢复整组」。

### 6.2 功能

| 功能 | 说明 |
|---|---|
| 选择数据集 | 全量加载数据集根目录 |
| 导入 | 自动识别两种 JSON：工具1导出（按选中区构建）；工具2自身导出（完整复原精筛状态：列入"图片对"的整对保留、"仅RGB/仅深度"恢复单边、未列出即排除、无保留的组进入已排除组） |
| 导出 | 精筛状态 JSON（格式见下），文件名 `精筛_数据集名.json`，可通过导入复原会话 |
| 拷贝 | 把当前保留的图片按**原路径结构**拷贝到 `filtering/data/`（`块/二级/场景/color|x.jpg`），不改动原数据集，带进度、可取消 |
| 图片配对 | 按去掉 `_color/_rgb/_depth/_dep/_ir` 后缀的文件主名配对；不成对允许单边 |
| 排除操作 | 图片对 / 单张RGB / 单张深度 / 整组，全部可恢复；排除后侧边树与统计实时同步 |

### 6.3 快捷键

| 键 | 功能 |
|---|---|
| `空格` | 放大查看当前块最上方组的第一个**图片对**（RGB/深度并排、共享缩放，与点击放大同一界面） |
| `A` / `D` | 上一对 / 下一对 |
| `W` | 排除当前图片对（已全排除时为恢复） |
| `S` | 恢复当前图片对 |
| 单边 | 放大界面中两侧图片下方的排除/恢复按钮 |
| `Q` / `Esc` | 退出放大查看 |

### 6.4 导出 JSON 格式

```json
{
  "图片对":   ["指向RGB图的绝对路径", ...],
  "仅RGB图":  ["绝对路径", ...],
  "仅深度图": ["绝对路径", ...],
  "全部组":   ["组绝对路径", ...],
  "统计信息": {
    "数据集根目录绝对路径": "", "最终保留的总块数": 0, "最终保留的总组数": 0,
    "最终保留的总RGB图数": 0, "最终保留的总深度图数": 0,
    "仅RGB图总数": 0, "仅深度图总数": 0
  }
}
```

「全部组」为导出时附加记录的会话信息（含完全排除的组），供导入时完整复原。

## 七、工具切换与数据集同步

- 工具1右上角「→ 工具2」、工具2右上角「→ 工具1」，**同一窗口内切换**，瞬间完成，全程不产生新窗口或弹窗；
- **数据集根目录全局唯一**：切换时若目标页面仍是旧数据集 → 立即清场并加载当前数据集（工具1→工具2且工具1有选中区时按选中区接续构建，否则全量加载；免二次确认弹窗）；若两页已是同一数据集 → 各自保留工作状态（快速来回切换不丢状态）；
- 首次进入工具2自动接续数据集与选中区，任何情况下切换工具都不需要重新选择数据集。

## 八、性能要求

- 图片数量大、组数量多时界面保持流畅：图片与界面卡片均异步、分批、按需加载渲染；
- 缩略图异步、可见优先；滚动、切换区域、筛选、恢复、导入导出、工具切换全程可响应；
- 批量操作（如排除整组）在界面内即时完成，不产生额外窗口。

## 九、验收清单

1. `uv run run.py` 直接进入工具1；顶栏为左功能按钮组 + 最右切换按钮，路径与统计信息仅在左下角状态栏；
2. 加载/导入开始时状态栏即进入过程提示，完成后即时显示新数据集统计；
3. A/D/S/空格 快捷键全程有效（焦点不在输入框时）；
4. 空格仅查看未筛选区最上方组；点击缩略图打开同一放大界面并定位；
5. 工具1导出 JSON → 工具2导入 → 精筛 → 导出 → 再导入可完整复原；
6. 工具2放大查看左右对称（共享缩放），W/S 排除恢复整对，单边红框反馈；
7. 两工具同窗切换，窗口不变，数据集自动同步，同数据集下来回切换状态保留；
8. 拷贝输出目录结构与数据集层级一致，原数据集未被改动。
