# filter-images 数据集筛选工具集

基于 **Python + PySide6** 的数据集筛选工具集，针对如下结构的数据集（“块” = 一级目录，“组” = 场景目录）：

```
数据集根目录/
└── 一级目录（工件描述）            ← 块
    └── 二级目录（工件名称+工件状态）
        └── 001（场景目录）         ← 组
            ├── color/          若干RGB图（.jpg/.png/…）
            ├── depth/          若干深度图（含16bit PNG，自动归一化显示）
            ├── camera_params/
            └── coco/
```

> 扫描规则：某目录下存在 `color/` 或 `depth/` 子目录即判定为“组”，不再向内递归；“块”为组的一级上级目录。因此同样兼容 `根目录/一级/场景` 的两级结构。

## 运行

项目使用 uv 管理依赖（见 `doc/使用uv管理项目环境依赖.md`），依赖已声明于 `pyproject.toml`（pyside6、pillow）：

```powershell
uv sync         # 安装依赖
uv run run.py   # 直接启动工具1（组级初筛）
```

工具2 两种方式进入：在工具1界面点击右上角「→ 工具2」同窗切换（数据集自动接续），
或直接运行 `uv run src/tool2_refine.py`。

> 数据统一组织在项目根目录的 **`filtering/`** 工作目录下：
> - `filtering/original_data/` — 原始数据集存放目录（「选择数据集」对话框默认从 `filtering/` 开始）
> - `filtering/data/` — 最终筛选拷贝输出目录（「拷贝」默认目标）
> - `filtering/*.json` — 导入 / 导出的筛选状态 JSON 默认位置
> - `filtering/test_data/` — 测试用模拟数据集

## 工具1：组级初筛（tool1_filter.py）

按“块-组”展示各组 color/ 内的 RGB 图，三区布局：**左侧选中区 / 中间未筛选区（主操作区）/ 右侧排除区**。

### 基本操作

| 操作 | 说明 |
|---|---|
| 选择数据集 | 选择数据集根目录并加载（需最先执行） |
| 每组显示数量 + 保存 | 组内图片数 ≥ count 时随机抽样 count 张显示（范围 1~500，默认 6） |
| 组按钮 | 每组卡片有「选中」「排除」；选中/排除区卡片有「恢复到未筛选」 |
| 块按钮 | 每个块头部有「一键选中」「一键排除」本块全部组 |
| 导出 / 导入 | 筛选状态 JSON，默认位于 `filtering/`，文件名 `粗筛_数据集名.json` |
| → 工具2 | **同一窗口内切换**到工具2：首次自动带上数据集与选中区；再次切换时两侧工作状态各自保留 |
| 查看图片 | 缩略图**左键**查看大图（滚轮缩放、拖拽平移、双击复位） |
| 复制图片 | 缩略图**右键**菜单：复制图片 / 复制文件路径 / 打开所在文件夹 |

移动规则：组被选中/排除后移动到目标区**最上方**；恢复时回到未筛选区**最上方**（其所属块同步置顶）。

### 快捷键（默认作用于区域最上方的组）

| 键 | 功能 |
|---|---|
| `A` | 选中最上方未筛选组 |
| `D` | 排除最上方未筛选组 |
| `S` | 撤销上一步（从选中区/排除区恢复到未筛选区） |
| `空格` | 放大查看未筛选区最上方的组 |
| `A` / `D` | 放大查看中：上一张 / 下一张 |
| `Q` / `Esc` | 退出放大查看 |

### 导出 JSON 格式

```json
{
  "未筛选区": ["组绝对路径", ...],
  "选中区":   ["组绝对路径", ...],
  "排除区":   ["组绝对路径", ...],
  "统计信息": {
    "数据集根目录绝对路径": "", "总块数": 0, "总组数": 0,
    "选中组数": 0, "排除组数": 0, "总RGB图数": 0,
    "选中总RGB图数": 0, "排除总RGB图数": 0
  }
}
```

导入校验：JSON 内记录的数据集根目录绝对路径与当前已设置路径不一致时**拒绝导入**。

## 工具2：RGB/深度对比精筛（tool2_refine.py）

接工具1的**选中区**结果做二次筛选：左侧可折叠目录树（块 → 组），右侧工作区成对显示当前组的 `RGB图/深度图 对`（不成对时允许空缺占位），该组图片**全部显示**（不抽样）。

### 基本操作

| 操作 | 说明 |
|---|---|
| 选择数据集 | 直接全量加载数据集根目录 |
| 导入 | 自动识别两种 JSON：**工具1导出**（按“选中区”构建目录树）或 **工具2自身导出**（完整复原精筛状态，含整对/单边/整组排除） |
| 工作区按钮 | 每个图片对：「排除图片对」「排除RGB图」「排除深度图」（均为开关，可恢复）；组头部：「排除整组/恢复整组」 |
| 目录树 | 组节点实时显示 `RGB n ｜ 深度 m`；完全排除的组自动移入「已排除组」节点（右键或工作区按钮可恢复整组）；对应块无剩余组时自动隐藏 |
| 查看图片对 | 缩略图**左键**并排查看 RGB/深度大图；**右键**复制等操作 |
| 拷贝 | 把当前保留的图片按**原路径结构**拷贝一份（`块/二级/场景/color|x.jpg`），不改动原数据集；默认目标为 `filtering/data/` |
| 导出 | 精筛状态 JSON，默认位于 `filtering/`，文件名 `精筛_数据集名.json`；可通过「导入」复原会话 |
| → 工具1 | **同一窗口内切换**回工具1：数据集保持一致，两侧工作状态各自保留 |

导航栏实时显示：`保留RGB n 张 ｜ 保留深度 m 张 ｜ 剩余组 g ｜ 块 b`。

放大查看（点击缩略图或空格）均为 **RGB/深度并排显示、左右共享同一缩放比例**（对称对比）；
初始按两图共同比例适配窗口（小图放大、大图缩小），滚轮缩放两侧同步，双击共同复位。

### 快捷键

| 键 | 功能 |
|---|---|
| `空格` | 放大查看当前块最上方组的第一个图片对（RGB/深度并排，与点击放大一致） |
| `A` / `D` | 上一对 / 下一对 |
| `W` | 排除当前图片对（当前对已全排除时为恢复） |
| `S` | 恢复当前图片对 |
| 单边操作 | 放大查看界面中两侧图片下方的「排除RGB / 排除深度」按钮（可恢复） |
| `Q` / `Esc` | 退出放大查看 |

### 导出 JSON 格式

```json
{
  "图片对":   ["指向RGB图的绝对路径", ...],
  "仅RGB图":  ["绝对路径", ...],
  "仅深度图": ["绝对路径", ...],
  "全部组":   ["组绝对路径", ...],
  "统计信息": {
    "数据集根目录绝对路径": "", "最终保留的总块数": 0, "最终保留的总组数": 0,
    "最终保留的总RGB图数": 0, "最终保留的总深度图数": 0,
    "仅RGB图总数": 0, "仅深度图总数": 0
  }
}
```

> 图片配对规则：按去掉 `_color/_rgb/_depth/_dep/_ir` 等后缀的文件主名匹配；一侧被排除后，剩余一侧计入“仅RGB图/仅深度图”。
> “全部组”为本工具额外记录的会话信息（含完全排除的组），供「导入」完整复原；导入时未列出的图片即视为已排除。

## 性能

- 缩略图**异步加载**（线程池 + LRU 缓存 + 可见优先调度），滚动时优先加载视口内图片；
- 大量组时界面卡片**分批增量创建**，避免一次性渲染导致卡顿/白屏；
- 深度图（16bit 等）按最小-最大拉伸归一化为 8bit 灰度显示，仅影响显示、不改动原文件。

## 文件结构

```
run.py              启动入口：直接启动工具1（界面内可同窗切换到工具2）
src/
├── common_ui.py     共享基础设施：数据集扫描/异步缩略图/流式布局/图片查看器
├── tool1_filter.py  工具1：组级初筛
└── tool2_refine.py  工具2：RGB/深度对比精筛
tests/               模拟数据集生成 + 冒烟测试
filtering/
├── original_data/   原始数据集存放目录（选择数据集默认从此开始）
├── data/            最终筛选拷贝输出目录
├── test_data/       测试用模拟数据集（由 tests/gen_dummy_dataset.py 生成）
└── *.json           筛选状态文件（导入/导出默认位置）
```
